# 스케줄링 프로그램

**기간**: 2023.9 ~ 2023.12

## 개요

본 프로젝트는 PyQt6를 사용하여 제작된 대학생 대상의 데스크톱 애플리케이션입니다. 사용자 계정 관리, 강의 데이터 관리, 시간표 관리 등 대학 생활에 필요한 여러 기능을 제공합니다. Selenium을 활용한 웹 스크래핑으로 강의 데이터를 가져오고, PostgreSQL 데이터베이스에 저장하여 관리합니다.

## 주요 기능

*   **계정 관리**: 사용자 로그인 및 계정 정보를 관리합니다.
*   **강의 데이터 조회**: 웹 스크래핑을 통해 최신 강의 정보를 가져와 사용자에게 보여줍니다.
*   **시간표 관리**: 사용자가 자신의 시간표를 추가, 수정, 삭제할 수 있습니다.
*   **데이터베이스 연동**: PostgreSQL 데이터베이스를 사용하여 사용자 정보, 강의 데이터, 시간표 등을 영속적으로 저장하고 관리합니다.

## 기술 스택

*   **GUI**: PyQt6
*   **데이터베이스**: PostgreSQL
*   **데이터베이스 연동**: psycopg2
*   **웹 스크래핑**: Selenium

## 파일 구조

*   `main.pyw`: 애플리케이션의 메인 진입점입니다.
*   `widgets/`: 애플리케이션의 UI를 구성하는 PyQt6 위젯 파일들이 위치합니다.
    *   `MainWindow.py`: 메인 윈도우 UI를 정의합니다.
    *   `AccountWidget.py`: 계정 관련 UI를 처리합니다.
    *   `ScheduleWidget.py`: 시간표 관련 UI를 처리합니다.
*   `utils/`: 애플리케이션의 핵심 로직과 유틸리티 파일들이 위치합니다.
    *   `PostgreSQLManager.py`: PostgreSQL 데이터베이스 연결 및 관리를 담당합니다.
    *   `DataManager.py`: 데이터베이스와 UI 간의 데이터 처리를 담당합니다.
    *   `WebScrapper.py`: 웹에서 강의 데이터를 스크래핑하는 기능을 담당합니다.
    *   `*.sql`: 데이터베이스 테이블 생성 및 데이터 관리에 사용되는 SQL 스크립트입니다.
*   `exe_folder/`: `pyinstaller`를 통해 생성된 실행 파일 및 관련 라이브러리가 포함되어 있습니다.

## 설치 및 실행 방법

1.  **의존성 설치**:
    ```bash
    pip install -r requirements.txt 
    # 또는 pip_list.txt, uv.lock 파일 참고
    ```
2.  **데이터베이스 설정**:
    *   `utils/create_db.sql` 스크립트를 사용하여 PostgreSQL에 필요한 테이블을 생성합니다.
    *   `utils/PostgreSQLManager.py` 파일 내 데이터베이스 연결 정보를 자신의 환경에 맞게 수정합니다.

3.  **애플리케이션 실행**:
    ```bash
    python main.pyw
    ```
